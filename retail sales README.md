# Warehouse and Retail Sales Analysis Dashboard

## Overview

This project presents an interactive Power BI dashboard developed to analyze warehouse and retail sales data. The dashboard provides valuable insights into sales performance, product categories, supplier contributions, and monthly sales trends.

## Objectives

- Analyze retail and warehouse sales performance.
- Identify top-performing product categories.
- Track monthly sales trends.
- Evaluate supplier contributions.
- Create interactive business intelligence reports.

## Tools Used

- Power BI Desktop
- Power Query
- Microsoft Excel / CSV Dataset

## Dataset Information

The dataset contains:

- Year
- Month
- Supplier
- Item Code
- Item Description
- Item Type
- Retail Sales
- Retail Transfers
- Warehouse Sales

## Dashboard Features

### KPI Cards
- Total Retail Sales
- Total Warehouse Sales
- Total Retail Transfers
- Total Item Records

### Visualizations
- Retail Sales by Item Type (Column Chart)
- Retail Sales Distribution by Item Type (Pie Chart)
- Monthly Retail Sales Trend (Line Chart)
- Supplier-wise Retail Sales Analysis (Bar Chart)
- Interactive Year Slicer

## Key Insights

- Warehouse sales are significantly higher than retail sales.
- Wine and Liquor categories contribute the highest sales.
- Monthly sales fluctuate throughout the year.
- Supplier performance varies across product categories.
- Interactive filters help explore data dynamically.

## Data Cleaning

The dataset was cleaned and transformed using Power Query by:

- Removing errors
- Detecting data type mismatches
- Formatting columns
- Handling missing values
- Preparing data for visualization

## Business Benefits

- Supports data-driven decision making.
- Helps identify top-selling product categories.
- Monitors supplier performance.
- Improves sales trend analysis.
- Enables interactive reporting.

## Project Outcome

The dashboard successfully transforms raw sales data into meaningful visual insights, helping stakeholders understand sales patterns and business performance.
